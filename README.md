# Manual Testing Portfolio

A collection of manual software testing work completed across academic projects, interview assignments, and live projects.

## About

This repository contains original Excel-based testing documents, including test cases, bug reports, and test reports where available. The files are preserved as submitted/prepared; they have not been rewritten as part of this portfolio organization.

## Notes

- The documents represent testing work performed at the time of each project or assignment.
- The websites and applications may no longer be accessible, so the historical test records may not be reproducible today.
- The presence of a test case or bug report does not imply that the issue is currently present or has been fixed.
- Project descriptions distinguish academic work, recruitment assignments, and live-project testing.
- These documents are shared for portfolio and learning purposes. Any confidential, personal, or restricted information should be removed before public distribution.

## Tools and Skills Demonstrated

The documents may demonstrate manual testing activities such as test case preparation, test execution, defect identification, and test reporting, depending on the deliverables available in each project.
